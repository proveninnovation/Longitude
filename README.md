# Longitude — shared resources

Published pages for a **Cessna Citation Longitude (Model 700, CE-700, Garmin G5000)**
two-crew setup in **Microsoft Flight Simulator 2024** (Asobo airframe, Working Title
G5000 avionics).

> [!warning] Sim use only — not for real flight
> Nothing here is an AFM. The checklist items are transcribed from Section XVII of a
> community-written *Model 700 Operators Guide* that is itself stamped *"for use in
> Microsoft Flight Simulator only"*. The crew mechanics are a proposal, not an
> operator's SOP.

## Unlisted, not secret

This repo is public only because that is what it takes to serve a page. It is **not meant
to be found**: `robots.txt` disallows everything, the page carries `noindex, nofollow`,
there is no `index.html`, and nothing links here. The site root returns 404 — only the
exact filename below resolves.

Treat the URL as the access control it is. Anyone who has it can read the page.

## Review mode

`Review` in the header is the editorial view. It numbers every line so a change can be
named precisely — *"reword 13.c"*, *"swap 13.2 and 13.6"* — and shows a six-cell
**confidence chip** on each one, saying how well sourced it is. Green means a real
Longitude crew is on record doing it; red means it is judgement and wants confirming.
Hover a chip for the evidence behind it.
